# Accessibility and inclusive participation

## Before the event

- Ask participants privately about access needs and preferred ways to contribute.
- Provide materials at least 48 hours in advance.
- Confirm the room, computers, and remote platform support keyboard-only use, screen magnification, and assistive technology.
- Offer a prepared environment so installation is not a prerequisite for participation.
- Make the learner guide and glossary available as plain Markdown or accessible HTML.

## During the event

- Read important visual patterns aloud and describe color, position, direction, units, and magnitude.
- Never use color as the only carrier of meaning; figures should also use labels, line styles, or annotations.
- Avoid “simple,” “obvious,” and speed-based praise.
- State keyboard commands as well as mouse instructions.
- Use frequent breaks and provide a quiet way to ask for assistance.
- Rotate team roles so operating the keyboard is not treated as the only technical contribution.
- Allow reflection responses to be spoken, typed, drawn, or recorded by a teammate.

## Figure-review checklist

- Descriptive title and labeled axes
- Units and time period stated
- Source and access date available nearby
- Adequate text size and contrast
- Pattern remains understandable in grayscale
- Key result expressible in one or two sentences without seeing the image
- Alt text drafted before publication

## Suggested alt-text pattern

“Chart type showing **what variables**, for **which place and period**. The main pattern is **direction and magnitude**. Important caveat: **missing data, uncertainty, or proxy**.”
