# Guided Explorer cell guide

Use `tracks/01_guided_explorer.ipynb`. Read headings in order; cell numbers can change as the lesson develops.

| Heading / action | Learner goal | Pause when |
| --- | --- | --- |
| Frame the question / discuss and customize | Choose an agricultural question and intended benefit | Sensitive knowledge is being requested |
| Load the prepared snapshot / run | Identify source, snapshot date and checksum | File or manifest missing/mismatched |
| Translate and audit / run | Notice excluded partial years | No complete years remain |
| Make and read one chart / run and discuss | Read place, period, PDSI and equal-weight regional meaning | A regional index is treated as a local measurement |
| Interpret / customize | State one supported finding and limitation | An unsupported causal or management claim appears |
| Stewardship and exit ticket / discuss | Record audience, storage, reviewer role and corrections | Sharing is proposed without the agreed review |

Minimum completion is a presentation addressing the seven questions, using completed or attempted work. No additional notebook is required. Refer to the learner quickstart for notebook keyboard controls.
