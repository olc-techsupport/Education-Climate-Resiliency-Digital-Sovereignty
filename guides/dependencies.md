# Core and optional dependencies

environment.yml is the core specification for the three tracks. GIS clients, basemap libraries and Daymet are not required for these activities. Install optional extension packages separately when an extension calls for them.

requirements-lock.txt is retained from the earlier broader environment as a historical reference; it is not a tested lock for the current core environment. Use environment.yml for workshop setup. A fresh core environment solve/install was not performed during this revision; validation records the existing execution environment used.
