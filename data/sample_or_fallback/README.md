# Included source snapshots

This directory contains instructor-prepared public NOAA, USGS and Census files and their manifest. The manifest records 2026-08-24 acquisition. These are historical snapshots, not current conditions.

Before class, run `python scripts/verify_snapshots.py`. Refresh only when needed, online, with `python scripts/prepare_workshop_data.py`; review the resulting manifest, source terms and coverage and rerun the lesson. Keep raw files and manifest together. Do not add sensitive or community-held data.
